# FPI Skills

Toolkit de loops para Claude Code y Cowork.

- /fpi:goal  — define un objetivo verificable y su condicion de "hecho".
- /fpi:loop  — itera hacia el objetivo con frenos (tope de ciclos, no-spinning, freno de acciones irreversibles).
- /fpi:ship  — lleva tests + tipos + lint + build a verde y se detiene en un mensaje de commit para tu revision.

Instalar en Claude Code:
  /plugin marketplace add Francosimon53/fpi-claude-skills
  /plugin install fpi@fpi-skills

En Cowork: pega la URL del repo en Ajustes -> Plugins -> marketplace personalizado.
